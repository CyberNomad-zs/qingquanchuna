考勤整理启动器 使用说明

把钉钉导出的月度考勤报表,一键整理成三张结果表;还能和现有结果表逐列比对,核对有没有算错。

准备开始前

  1. 把当月考勤报表放进工具所在文件夹。从钉钉考勤系统导出 *月考勤报表_起_止.xlsx 后,存到这个目录:
    E:\project\清泉出纳\
    文件名必须含「考勤报表」四个字

    启动器靠文件名识别报表,扫描目录里所有 *考勤报表*.xlsx。名字里没有这四个字,下拉框里就看不到。

  2. 电脑装过 Python 3,安装时勾过「Add python.exe to PATH」。没装过的话,启动器会报 Python not found —— 见下面常见问题。

操作四步出结果

  1. 双击 考勤整理启动器.bat。会弹出一个深色窗口,标题「清泉出纳 · 考勤整理启动器」。没有黑色命令行框弹出来是正常的(启动器刻意做了无黑窗启动)。

  2. 在「考勤报表」下拉框里选当月报表(就是上一步放进去的那个文件)。如果下拉框是空的,先把报表放进目录,再点旁边的 刷新。

  3. 点 整理 —— 只整理,出结果;或点 整理并比对 —— 整理完再和现有的 考勤整理结果.xlsx 逐列核对差异。弹窗确认后,底部「运行输出」会开始滚字。

    勾上「整理后逐列比对现有结果表」再点 整理,效果和直接点 整理并比对 一样。

  4. 等输出跑完,打开结果文件。看到 --- 结束 exit=0 --- 就是成功,会弹窗问「打开结果文件?」,点「是」直接打开。结果文件名形如 7月考勤整理结果_校验.xlsx,和启动器在同一个目录。

  5. 整理无误后,点 上传到飞书。把当月的考勤原始报表 + 整理结果一起传到飞书多维表格。脚本会自动从文件名认出是几月,在飞书里建/复用 5 张「{月}」前缀的表(考勤报表、打卡时间明细、考勤结果表、打卡异常说明、其他员工),清空后写入当月数据,历史月表不动。弹窗确认后底部跑进度,跑完问「去飞书查看?」。

    每月只点一次就行;同月重复点会把该月表清空重写,不会重复堆数据。

计算口径(整理结果表)

净事假/调休 = 假期 − 加班(不够抵为 0);净加班 = 加班 − 假期(不够抵为 0);7.5 小时 = 1 天;实际出勤 = 应出勤 − 净事假/调休 ÷ 7.5 − 年假 − 病假 − 婚假 − 育儿假(保留小数,不四舍五入);迟到次数直接抄报表。

当月入职的新人也进主表,应出勤天数直接用钉钉报表给的值(钉钉已按入职日起算,如 7/27 入职给 5 天),实际出勤就是入职后那几天的正常出勤,脚本不另外重算。

月份是脚本自己认的

脚本从报表文件名里的 20260701_20260731 或「7月」认出年月,自动给表加「{月}」前缀。7 月的报表就建「7月考勤报表」一套,8 月的就建「8月」一套,互不干扰。每月新建,历史月表永远不动。

上传前提:先整理出结果

点 上传到飞书 前,目录里必须有当月的 *考勤整理结果_校验.xlsx(就是上一节「整理」生成的那个)。没有的话会弹「未找到整理结果」,先点 整理 再上传。

同月可重复点,不会堆数据

同一个月重复上传,脚本认出表已存在就复用,先把该月表里的旧数据清空,再写当月最新数据。所以改了数据重传不会重复,也不会把旧月表弄乱。

上传后:把两张原始表拖进月份分组(手动,1 分钟)

飞书多维表格左侧可以把表收纳进「分组」(像文件夹)。脚本只负责建表和灌数据,归组要手动做一下:上传完成后,在飞书左侧新建一个分组(名字如「8月」),把当月的两张原始数据表——{月}考勤报表 和 {月}打卡时间明细——拖进这个分组。结果表/异常说明/其他员工留在外面即可。这样几个月下来,左侧按月份分组清清爽爽。

工具窗口右上的四个按钮

  • 打开结果目录 —— 在资源管理器里打开 E:\project\清泉出纳\,找结果文件和日志都从这儿进。
  • 环境自检 —— 打印本机 Python 和 openpyxl 版本,确认环境能不能跑。第一次用或换电脑后先点一下。
  • 安装依赖 openpyxl —— 提示缺 openpyxl 时点这个,自动 pip install openpyxl。
  • 停止当前任务 —— 整理卡住或想中断时点,杀掉正在跑的进程。

排障常见问题

双击 bat 闪一下就没了,或弹窗说 Python not found。

电脑没装 Python 3,或装的时候没勾「Add python.exe to PATH」。去 python.org 装 Python 3,安装界面务必勾上那个 PATH 选项,装完重新双击 bat。

下拉框是空的,「考勤报表」选不到东西。

报表文件没放对位置,或文件名不含「考勤报表」。把钉钉导出的报表放进 E:\project\清泉出纳\,确认文件名带「考勤报表」四字,再点 刷新。

运行输出里报 No module named 'openpyxl'。

缺处理 Excel 的依赖。点 安装依赖 openpyxl,装完再点整理。

弹窗提示「任务失败 exit=非0」。

看运行输出面板最后几行的报错。完整日志已存到 logs\ 文件夹,点 打开结果目录 → 进 logs → 打开最新的 gui-*.log 把报错行发给我。

整理完没弹「打开结果文件?」的窗。

说明结果文件没生成成功,运行输出里通常已经有报错行。按上一条找日志。

「整理并比对」和直接「整理」出的结果一样吗?

出的结果文件完全一样。比对只是额外把这次生成的「考勤整理结果」sheet 跟目录里现有的 考勤整理结果.xlsx(不含 _校验 的那个)逐列核对,在运行输出里打印差异;没差异会显示 ✅ SHEET1 与现有结果表逐列一致。

点「上传到飞书」提示「未找到整理结果」。

目录里没有当月的 *考勤整理结果_校验.xlsx。先在下拉框选好当月报表,点 整理 生成结果文件,再点 上传到飞书。

上传时运行输出报错,飞书里没建表。

看运行输出最后几行的报错行。常见是网络不通或飞书凭据过期。完整日志在 logs 文件夹(点 打开结果目录 → 进 logs → 打开最新 gui-*-上传到飞书.log)。把报错行发给我。

同一个月重复上传会怎样?

脚本认出该月表已存在就复用,先清空旧数据再写当月最新数据,不会重复堆,也不会动历史月表。所以改完数据放心重传。

上传后表都堆在左侧,怎么按月份归类?

飞书多维表格左侧能建「分组」。每月上传完,手动新建一个分组(如「8月」),把当月的 {月}考勤报表 和 {月}打卡时间明细 两张原始表拖进去就行。归组是飞书界面手动的,脚本不管这部分。
